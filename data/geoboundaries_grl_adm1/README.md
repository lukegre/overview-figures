# geoboundaries_grl_adm1

Greenland municipality boundaries (ADM1).

## Contents

`geoBoundaries-GRL-ADM1.geojson`: polygons of 5 municipalities and the
Northeast Greenland National Park (geoBoundaries gbOpen, 2020 vintage),
name field `shapeName`, EPSG:4326.
